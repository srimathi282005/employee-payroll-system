# Task 5 – Employee Payroll System

## Scenario

A company wants to automate the monthly salary calculation of its employees.

## Requirements

- Store employee ID, name, basic salary, allowance, overtime, and deductions using a structure.
- Calculate gross salary, tax, deductions, and net salary using arithmetic operators.
- Use conditional statements to calculate bonuses based on employee performance.
- Create separate functions for salary calculation and payslip generation.
- Pass employee information using pointers so the functions can update the record.
- Display a complete salary statement for each employee.

## Concepts Used

- Structures
- Pointers
- Functions
- Operators
- Conditions

## Program Features

1. Store employee details.
2. Calculate performance-based bonus.
3. Calculate gross salary.
4. Calculate tax and deductions.
5. Calculate net salary.
6. Generate and display the employee payslip.
